# Security policy

## Reporting a vulnerability

Please report security problems privately, not as public issues:

- use the repository's **Security** tab, then **Report a vulnerability**, or
- email <pugforecast@gmail.com>.

Say what you found, which version or build it affects, and how to reproduce it. Leave real API keys
and personal data out of the report.

## Supported versions

Fixes go into the latest release and `main`.

## Secrets

The project holds no secrets: API keys for OpenWeather and Pirate Weather are entered by each user
and stay in that device's keychain or environment. If you find a key or credential anywhere in the
repository or its history, please report it as above.
